# Referências de interface (o app em si)

Telas e páginas que servem de referência para a **interface do SocialHub** — não para
as artes que ele gera.

Origem: board `pinterest.com/devdamieen/layouts-projeto-app`, puxado em 2026-07-28.
Conteúdo: landing pages de SaaS, sites, telas de app mobile.

Não confundir com `docs/referencias-layout/`, que guarda referências de **arte de post**
(feed, carrossel, story) e alimenta o catálogo em `lib/layouts/structures.js`.

Imagens fora do git — insumo local.
