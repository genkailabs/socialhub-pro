# Referências de layout

Jogue aqui prints de artes cujo layout você gostou.

- `post/` — quadrado (feed)
- `carrossel/` — slides
- `story/` — vertical

Só as imagens. Não precisa renomear, não precisa anotar nada.

Depois é só avisar: "coloquei referências lá". O Claude olha uma por uma e
escreve a planta baixa de cada layout em `lib/layouts/structures.js`, que é o
catálogo que o Composer usa para montar arte.

As imagens ficam fora do git (ver `.gitignore`) — são insumo local. O que vira
patrimônio do repositório é a planta extraída, não o print.
