# Vídeo 01 — Como configurar seu projeto

**Arquivo-fonte:** `E:\Claude Curso\videos\1. Como configurar seu projeto (2min).mp4`  
**Duração real:** 10m23s (o nome do arquivo indica 2 min, mas o conteúdo é mais longo).  
**Método de leitura:** transcrição local e análise das instruções narradas.

## Configuração ensinada

1. No Claude.ai, criar um **Projeto** e dar um nome.
2. Colar o `system-prompt-maquina-carrosseis-v4.md` nas instruções do Projeto.
3. Enviar os outros seis arquivos `.md` na aba de arquivos/conhecimento.
4. Iniciar um chat e escolher um dos dois caminhos:
   - **1:** enviar conteúdo existente (artigo, transcrição, aula, vídeo etc.).
   - **2:** partir de uma ideia, observação ou tema.

## Fluxo demonstrado

1. Informar contexto da marca: @, nicho, cor, estilo, objetivo, número de slides e quantidade de imagens.
2. Receber 10 opções de headline; escolher uma ou pedir alteração.
3. Revisar a espinha dorsal antes da copy final.
4. Revisar/aprovar o texto; só depois enviar imagens e gerar o layout.
5. Receber um HTML como preview, dar feedback de layout/texto pelo chat e, apenas quando estiver aprovado, pedir `exportar` para gerar PNGs.

## Orientações práticas mostradas

- Ajustes devem ser feitos diretamente pelo chat: fonte, legibilidade, distribuição de imagens e layout.
- É possível adicionar imagens a outros slides depois da primeira versão.
- O HTML é uma etapa de revisão; o PNG só vem após a aprovação do preview.
- A ferramenta é apresentada como uma alternativa mais rápida para quem não domina Figma/Canva, não como substituição integral dessas ferramentas.
- O vídeo recomenda Sonnet 4.6 sem pensamento estendido no Claude.ai. Isto é uma orientação específica do curso/Claude, não uma regra para o SocialHub ou para o Codex.

## Divergência entre os materiais

| Fonte | Orientação sobre memória do Projeto |
| --- | --- |
| Guia de Instalação | Limpar a memória na configuração inicial para evitar assumir uma marca errada. |
| Vídeo 01 | Depois de configurado, pedir para salvar preferências de marca e linguagem para usos futuros. |

Leitura inicial: as duas instruções podem coexistir se houver separação por marca e controle explícito do usuário. No SocialHub, qualquer memória futura deve ser isolada por marca, editável e nunca aplicada silenciosamente a outra marca.
